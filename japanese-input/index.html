假名工坊试打原型 0.2

右手选行，左手选段。每次按键，都能看清发生了什么。

● 在浏览器中运行

请在电脑上使用带数字小键盘的实体键盘，并切换到系统英数输入。屏幕上的键位图用于提示，不是触屏键盘。输入与回放在当前浏览器内处理。

试打区

平假名
黑色：已确定蓝色：编辑中虚线：待定あ段

浏览器原型请使用系统英数输入；Caps Lock 切换的是原型内部模式。

退格 / 小键盘 .：删除已配对假名；待定行、无效提示或候选中回退一步。Esc / 撤销：恢复上次操作。

示例读音：か／かな／にほん。小键盘 + 变换，↑↓ 选择，Space 或 Enter 接受。

输入状态

未聚焦
按住与松开，是两种动作

按住行键，再按段键：追加假名。
行键松开且配对完成：段键修改前字。

没有时间容差

行键必须先到。段键先到时，按改字或英文字母规则处理。
